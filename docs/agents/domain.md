# Domain Docs

This repository uses a single-context layout.

Before engineering work:

1. Read root `CONTEXT.md` when it exists.
2. Read relevant ADRs under `docs/adr/`.
3. Use the domain terminology defined in `CONTEXT.md`.
4. Explicitly report conflicts with existing ADRs.
5. If these files do not yet exist, continue without treating that as a blocker.
